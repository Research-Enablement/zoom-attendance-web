How this works

This page runs the zoom-attendance pipeline's Python code inside the browser with Pyodide. Your files are read into this tab's memory and never uploaded. Reloading the page clears everything that has not been downloaded.

Matching: attendees with an email are matched to the people list, or added to it. Attendees without an email are matched by their Zoom name if that name has been seen before. Anyone else is listed in step 3 for you to match before the session is saved.

Only one person should add sessions to a history file at a time. If two people each add new people to their own copies, the same ID can be given to two different people.

The session pages and the overview show counts only, never names.

This page counts visits and which buttons are used (for example "session saved") with Google Analytics, to see how much the tool is used. It never sends your files, names or emails.
